Escenarios:
- Automatizacion equipos en base a la temperatura/humedad
	El objetivo general:
	El producto de software logre comunicarse con un sistema climatico del cual se base para recompilar informacion del clima del 
	dia siguiente, para que pueda prender el sistema de calefacción en una temperatura estandar y que a su vez, pueda 
	preguntarle al cliente si desea aumentar o disminuir dicha temperatura para que se adapte a su sensación termica.




- Comparacion entre registros:
	El objetivo general:
	El producto compara registros semanales para ver diferencias entre gastos/consumos y equipos. Mostrando graficas, tablas.


- Alertas de consumo electrico anormal
	El Objetivo general:
	El producto logra comunicarle al cliente que en el caso de que se detecte un consumo anormal de electricidad con los dispositivos
	electricos conectados al programa. Largue un aviso en el cual se especifique el equipo, gasto y consumo el cual genere esta 
	advertencia.  


- Registro de temperaturas, consumo/gasto, tiempo de calentado/enfriado de habitaciones, horas de uso, etc...

	El Objetivo general:
	El producto genera registros de historicos de las temperaturas, gastos/consumos, tiempo de calentado/enfriado, horas de uso, etc.
